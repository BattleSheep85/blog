# Naming research: replacement for TrueRank

Date of checks: 2026-08-03. All availability, trademark, search, and social
checks below are live checks done on this date, not memory. Method is stated
for each check. Where a check was blocked or inconclusive, this document says
so plainly.

## Why TrueRank must change

Google Search Console shows four months of query data for the site. The only
terms Google associates with it are "truerank," "trueranker," and "ranktracker
vs trueranker." These are searches for SEO rank-tracking software. TrueRanker
and RankTracker are established products in that category. TrueRank competes
with them for a search intent it does not serve. The name must not read as an
SEO tool, a rank tracker, or a marketing-analytics product.

The site must also disclose that it is an AI product. The new name must sit
next to that disclosure without contradicting it. A name that implies human
editors or a hands-on test lab would be a false claim.

## Method

- **Domain availability**: RDAP, primarily via `rdap.org`, cross-checked
  against the authoritative registry RDAP endpoint (for example
  `rdap.verisign.com` for `.com`, `rdap.identitydigital.services` for `.io`)
  when a result looked inconsistent. A 404 response means the name is not in
  the registry, so it is available. A 200 response means it is registered,
  and this document reports the registrar, registration date, and status
  codes found in that record.
- **Price**: for available names, the price given is the standard market
  registration rate for that TLD, not a live quote from a registrar, and this
  document says so each time. For registered names, this document reports
  what the live site or redirect shows (parking page, marketplace listing,
  live business) as evidence of price, and gives an exact figure only when
  one was directly observed.
- **Trademark**: the unofficial USPTO TESS mirror
  (`uspto-trademark.appspot.com`) is dead and returned HTTP 404 on every
  query. `trademarks.justia.com` and `trademarkia.com` both blocked automated
  access with HTTP 403. Because of this, **no candidate name in this
  document has a confirmed, authoritative trademark clearance.** Every
  finding below is a WebSearch fallback at best. A direct search at
  `tmsearch.uspto.gov`, or a trademark lawyer, must confirm before any name
  is adopted.
- **Search collision**: a live WebSearch for the bare candidate name, with no
  extra terms added.
- **Social handles**: a live fetch of the X profile URL and the Reddit user
  and subreddit URLs. X blocked automated content reads with HTTP 402 on
  every query, and a raw HTTP 200 from X's app shell does not distinguish an
  existing account from an empty one, so X results are inconclusive except
  where a name turned up directly in search results (as with AskReal).
  Reddit blocked every automated request (both `curl` and WebFetch) with a
  generic bot-policy page, for all 12 candidates, both `/user/` and `/r/`
  paths. **No Reddit result in this document is confirmed.** This must be
  checked by hand in a browser before a name is adopted.

## What the AI-disclosure and abstract-word requirements produced

Two candidates were chosen to lean into the AI disclosure directly: **AskReal**
and **AIVerdict**. AIVerdict failed on a direct collision with a live AI
product in the SEO-audit space, the same disease this project must avoid.
AskReal survives: its `.com` is an abandoned storefront rather than an active
brand, its `.io` is confirmed free, and its only real conflict is a small,
inactive personal X account.

Four candidates were chosen as abstract or invented words: **Verdiq**,
**Sourcely**, **Verdictly**, and **Clarabuy**. Three of the four collided
directly with an existing, live, similarly-branded product (Verdiq, Sourcely)
or a live marketplace price tag plus an adjacent-vertical collision
(Verdictly). Only Clarabuy came back clean on both the domain check and the
search-collision check. This is worth stating plainly: coined, AI-adjacent
words are a crowded space right now, and most short, pronounceable coinages
in this exact conceptual territory are already taken by other AI startups.

## Top three

**1. Clarabuy.** The only candidate with a confirmed, genuinely available
`.com`, checked twice by RDAP. No live competing brand appears in search
results. Short, 8 letters, no hyphen, no number, not a misspelling. The
weakness is that the name does not carry "honest evidence-based advice"
on its own, it will need a strong tagline to carry that meaning, and its
trademark and social-handle status are not yet confirmed by an authoritative
source.

**2. Truthcart.** Directly on-message (truth, evidence) with a shopping-cart
ending that reads as commerce, not SEO software. No dominant brand collision.
The `.com` is not free, it resolves through a HugeDomains resale listing at an
unconfirmed but likely four-figure price. The `.co` is free at standard rates
if the owner does not want to pay for the `.com`.

**3. AskReal.** Fits the AI-disclosure requirement well, an assistant you ask
for a straight answer. The `.io` is confirmed free. The `.com` is an
abandoned foreign storefront, not obviously for sale, so it may or may not be
obtainable, and a small inactive account already holds the `@askreal` X
handle.

## Recommendation

**Clarabuy**, with the `.com` domain.

**The case for it**: it is the only name of the twelve checked where the
`.com` is confirmed, free, and not parked or listed for resale. None of the
others achieved this. Every other clean-sounding name in this list turned out
to be owned by an existing AI startup working in an adjacent space, an
active marketplace listing with a real price tag, or an unrelated live
business. Clarabuy also passed the search-collision check cleanly: nothing
currently trades under this name. It is short, easy to say, easy to spell,
and contains no hyphen, number, or deliberate misspelling.

**The honest case against it**: the name itself does not say "honest,
evidence-based, cited" the way Truthcart or AskReal does. It will carry that
meaning only through the tagline, the about page, and the AI-disclosure
banner, not through the word itself. Its trademark status has not been
confirmed by an authoritative source, the automated USPTO checks used in
this research were blocked or dead, so this must be checked directly at
`tmsearch.uspto.gov`, or by a trademark lawyer, before money or engineering
time is spent on it. Its social-handle status on X and Reddit is also
unconfirmed for the same reason, and should be checked by hand in a browser
before launch. If either check turns up a real conflict, Truthcart (buying
the `.com` through HugeDomains) or AskReal (registering the free `.io`) are
the next best options in that order.

## Migration cost, if the owner moves off `chrisputer.tech`

Moving to a new domain touches four things:

1. **Cloudflare Worker routes.** The Worker's routes are bound to the current
   domain in `wrangler.toml` (or the dashboard's custom-domain binding for
   the zone). Moving means adding the new domain as a zone in Cloudflare,
   pointing its DNS at the Worker, and updating the route pattern. This is a
   configuration change, not a code change, and can run alongside the old
   domain during a transition.
2. **The affiliate program's registered site.** Amazon Associates (and any
   other affiliate program in use) has the current domain on file as the
   approved traffic source. The new domain must be added to the account
   before affiliate links on it will earn commission. This is an account
   setting change in the affiliate dashboard, not a code change.
3. **Search Console property.** Google Search Console tracks `chrisputer.tech`
   as its own property. A new domain is a new, separate property with no
   history. The current property can stay in place as a historical record,
   or be removed, this is the owner's call and has no cost either way.
4. **What is lost by leaving `chrisputer.tech`.** Search Console's own four
   months of data for the current domain shows only three query terms, all
   of them people searching for unrelated SEO software, not queries that
   found and used this product. There is no evidence of backlinks or organic
   traffic worth preserving. This document's own read of that data
   (established fact, since it is quoted directly from the project brief) is
   that there is very little to lose by moving now, and moving later would
   only add more low-value history to migrate away from.

## What could not be verified

Trademark clearance and social-handle availability could not be confirmed
for any of the 12 candidates through automated tools in this session. The
unofficial USPTO TESS mirror used for this research is dead, Justia and
Trademarkia both blocked automated access, and Reddit blocked every
automated request outright. Before adopting any name from this list, run a
direct search at `tmsearch.uspto.gov` (or use a trademark lawyer) and check
the X and Reddit handles by hand in a logged-in browser.
