# Naming research, round two: replacement for TrueRank

Date of checks: 2026-08-04. This is a second pass. The first pass produced
`docs/naming-2026-08.md` and recommended "Clarabuy." The owner rejected it,
correctly. Clarabuy won only because it was the one candidate with a free
`.com`, not because it was a good name. It says nothing about what the
product does, and "Clara" reads as a woman's first name, which sits badly on
a site whose whole point is that no human wrote the reports.

**The `.com` requirement is lifted for this round.** Every credible TLD is in
play. Names are judged on merit first, availability second.

## What the product actually does

Verified from the source code and the project brief:

1. It cites its sources. Every claim traces back to a real page.
2. It filters fake reviews and affiliate spam. A promotional source cannot
   be the sole basis for a recommendation.
3. It never invents products or specifications.
4. It abstains when the evidence is thin, and says so. Almost nothing else
   in this market admits uncertainty.

It discloses openly that reports are AI-generated, with no human editor. It
earns affiliate commission, and commission does not affect ranking.

Target positioning: it shows its receipts, and it admits what it does not
know.

## Hard exclusions carried into this round

- No name built on "rank." Google Search Console shows the only queries
  associated with the current site are "truerank," "trueranker," and
  "ranktracker vs trueranker." TrueRank is being read as SEO rank-tracking
  software, and this project must not repeat that mistake with a new name.
- No name that implies human testing, a lab, or hands-on review. Nobody
  tests anything by hand. That claim would be false.
- No hyphens, no digits, no deliberate misspellings.

## Method

- **Domain availability**: RDAP, checked live with
  `curl -sL -o /dev/null -w "%{http_code}" https://rdap.org/domain/<name>`,
  following redirects. A 404 means the name is not in the registry, so it is
  available. A 200 means it is registered. Every result in the table below
  is the exact code seen on this date, not an assumption. Where a result
  looked ambiguous, a direct registry RDAP endpoint was tried as a
  cross-check (for example `rdap.verisign.com` for `.com`).
- **Price**: the published first-year and renewal price for the TLD, from
  Porkbun's public TLD pricing pages, which loaded reliably. Namecheap's
  pricing pages returned HTTP 403 to every automated fetch attempt in this
  round, so Namecheap is not used as a price source here. Renewal price is
  flagged wherever it is markedly higher than the first-year price, since
  that gap is a common registrar trap.
- **Trademark**: `tmsearch.uspto.gov` is a JavaScript-rendered application.
  No working public search endpoint could be reached by an automated tool in
  this round either, the same result the first round found. Every trademark
  line below is a WebSearch fallback, not an authoritative USPTO record
  search. Where a fallback search surfaced a specific live or dead
  registration, this document names it. **No candidate in this document has
  confirmed, authoritative trademark clearance.** A direct search at
  `tmsearch.uspto.gov`, or a trademark lawyer, must confirm before any name
  is adopted.
- **Search collision**: a live web search for the bare candidate string,
  with no extra terms added, checking whether an existing company, product,
  or dominant common usage already occupies the name.
- **Social handles**: not checked in this round. This must be done by hand
  in a browser (X, Reddit, Instagram) before any name is adopted.

## Trademark caution worth naming directly

Two live, registered USPTO marks turned up as direct hits during this
search, even through the limited WebSearch fallback:

- **"EVIDENTLY"** (Registration 4214171), Class 035 advertising services,
  registered 2012, status live and incontestable. Anything built on
  "evidently" risks this mark.
- **"VERDICT PRO"**, an exam-scheduling SaaS mark, different class
  (education software), lower direct risk but confirms "verdict" is already
  claimed territory in a nearby space.

Neither of these hits came from a confirmed, complete USPTO search. They are
reported because they surfaced anyway, and a confirmed hit found by accident
is a stronger warning than a clean result from an incomplete search.

## Top five

**1. Cited.guide.** Confirmed available (RDAP 404). No dominant search
collision, only generic university citation-style guide pages, not a
competing brand. The word "cited" states exactly what the product does,
every claim traces to a real source, and it carries no overlap with
tracking, analytics, or SEO vocabulary, so it does not repeat the TrueRank
confusion. Price is $6.18 first year, $33.47 renewal, on the steep side for
a small TLD but affordable. `.guide` is a legitimate, non-spam TLD used by
real reference and content sites.

**2. Backed.report.** Confirmed available (RDAP 404). No dominant search
collision. "Backed" states that every recommendation rests on real evidence,
directly answering the "a promotional source cannot be the sole basis"
design rule. `.report` reads naturally as the output format. Price is
$6.69 first year, $20.08 renewal, the cheapest renewal of any strong
candidate found.

**3. Sourced.reviews.** Confirmed available (RDAP 404). `.reviews` is the
most immediately legible TLD of any candidate in this list, it tells a
visitor exactly what kind of site this is before they read a word of copy.
Moderate collision risk from two small, unrelated companies using the bare
word "Sourced" in different industries, not the review or AI-tool space.
Renewal, at $49.95, is the most expensive of the group.

**4. Traced.report.** Confirmed available (RDAP 404). Reads well as a
sentence, "traced" states that every claim is followed back to its source,
matching the citation and evidence design rules closely. The one real
caution: "traced" is heavily used in software as a technical term
(distributed tracing, application performance monitoring), which echoes,
faintly, the same kind of tool-vocabulary confusion that sank TrueRank.
Worth a plain warning, not a disqualification.

**5. HasReceipts.com.** Confirmed available (RDAP 404). "Receipts" is
common internet shorthand for "the proof is real," a close, colloquial match
for the citation and evidence design rules, and it is the only `.com` in
this top five. Real risk: the neighboring domain space
(NeedReceipt.com, CreateReceipt.com, MakeReceipt.com, GetReceipts.com) is a
busy niche of literal receipt-scanning and expense-tracking apps, so a
visitor's first guess at what "HasReceipts" does may be wrong.

## Recommendation

**Cited.guide.**

**Tagline:** Every claim, cited. When the evidence runs out, we say so.

**First line a visitor reads:** An AI wrote this report. Every claim links
to a real source, and we tell you when the evidence is too thin to trust.

Read together, the name, the tagline, and the first line communicate both
required ideas inside about two seconds: it shows its receipts (cited,
every claim links to a real source), and it admits what it does not know
(when the evidence runs out, we say so).

**The case for it:**

- The domain is confirmed available by a live RDAP check on this date
  (`https://rdap.org/domain/cited.guide`, HTTP 404).
- No dominant search collision turned up. The only search results at this
  exact phrase are unrelated university citation-style guide pages, not a
  competing brand, so there is no existing identity to fight for attention
  or trademark space.
- "Cited" is precise. It means exactly what the product does, and it does
  not overlap with tracking, ranking, or SEO-tool vocabulary, so it avoids
  the exact confusion that forced TrueRank to change.
- `.guide` completes the phrase honestly: a guide, and everything in it is
  cited. That reads as a research and comparison product, not a lab, not a
  human reviewer, and not an SEO tool.
- The price is affordable for a small business, and `.guide` is a real,
  non-spam TLD already used by legitimate content and reference sites.

**The case against it:**

- Trademark clearance is not confirmed. Automated checks against
  `tmsearch.uspto.gov` were blocked in this round, the same as the first
  round. Only a WebSearch fallback was run. It found no conflicting mark,
  but that is not an official clearance. This must be checked directly at
  `tmsearch.uspto.gov`, or by a trademark lawyer, before any money or
  engineering time is spent on the name.
- `.guide` renewal, at $33.47 a year, is more than three times the
  advertised first-year price, and higher than the plainer `.report`
  alternative, which renews at $20.08. The gap is small in absolute dollars
  but worth entering with eyes open.
- `.guide` is a less familiar TLD than `.com`. Some visitors will not
  recognize it on sight, and it is a small extra step to type correctly
  from memory compared with `.com`.
- Social-handle availability on X, Reddit, and Instagram was not checked in
  this round and must be confirmed by hand in a browser before launch.
- The name "Cited" alone does not carry the "admits what it does not know"
  half of the positioning. That half rides entirely on the tagline and the
  about page, the same structural weakness the first round flagged for
  Clarabuy, though here the name at least carries the "receipts" half on
  its own, unaided.

If Cited.guide fails trademark or social-handle clearance, Backed.report is
the next best option: same clean collision profile, cheaper renewal, and no
`.guide`-versus-`.com` recognition tax.

## What could not be verified

- **USPTO trademark clearance** for any of the 29 candidates.
  `tmsearch.uspto.gov` is a JavaScript-rendered application with no working
  public search endpoint reachable by automated tools in this round. Every
  trademark line in this document is a WebSearch fallback, not an
  authoritative record search. This must be confirmed directly at
  `tmsearch.uspto.gov`, or by a trademark lawyer, before adopting any name.
- **Exact asking prices** for domains confirmed listed for sale through a
  GoDaddy, Sedo, or Afternic broker page. Every broker page fetch attempted
  in this research returned HTTP 403.
- **Live-versus-parked status** for a small number of registered domains
  where the site itself could not be reached at all (`proofshelf.com`,
  `openreceipts.com`, `sourced.report`), due to connection or TLS errors
  from this network.
- **Exact `.com` renewal price** beyond Porkbun's stated flat $11.08.
  Porkbun's page states the price does not change year to year, but did not
  show registration and renewal as two separate line-item numbers.
- **Social-handle availability** on X, Reddit, and Instagram. Not checked
  in this round at all. Check by hand in a logged-in browser before
  adopting any name from this document.
